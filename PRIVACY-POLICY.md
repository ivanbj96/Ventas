# Política de Privacidad - TillUp POS

## 1. Introducción
TillUp POS es una aplicación web progresiva (PWA) diseñada para la gestión de ventas, inventario y clientes, optimizada para dispositivos móviles y escritorio.

## 2. Recopilación de Datos
- **Datos almacenados:** productos, clientes, ventas, deudas, movimientos, configuraciones y backups.
- **Origen:** Todos los datos son ingresados manualmente por el usuario.
- **No se recopilan datos personales sensibles** (como documentos de identidad, tarjetas, etc.).

## 3. Uso de los Datos
- Los datos se utilizan exclusivamente para el funcionamiento interno de la app y la generación de reportes, balances y backups.
- No se usan para fines publicitarios ni de análisis externo.

## 4. Almacenamiento y Seguridad
- Los datos se almacenan localmente en el dispositivo del usuario mediante LocalStorage e IndexedDB (localForage).
- Los backups generados pueden ser descargados por el usuario y son responsabilidad del mismo.
- No se envían datos a servidores externos ni a terceros.

## 5. Compartición de Datos
- **No se comparten datos con terceros.**
- El usuario tiene control total sobre la exportación/importación de sus datos.

## 6. Eliminación y Control de Datos
- El usuario puede eliminar sus datos desde la app o borrando el almacenamiento del navegador.
- Los backups descargados pueden ser eliminados manualmente por el usuario.

## 7. Cambios en la Política
- Cualquier cambio en esta política será notificado en futuras versiones de la app y en este archivo.
