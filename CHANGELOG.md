# Changelog - TillUp POS

## [1.4.0] - 2024-06-XX

### 🐔 Edición y Corrección de Ventas de Pollos
- Ahora puedes editar cualquier venta de pollos registrada para corregir cantidad, peso, precio, cliente, abono, etc.
- Las estadísticas y reportes se actualizan automáticamente tras la edición.

### 🔒 Backup y Seguridad Mejorados
- Backup automático descargable cada 5 minutos (opcional, configurable)
- Backup manual tras operaciones críticas (ventas, clientes, productos)
- Exportación/importación de datos en JSON
- Restauración fácil desde backup descargado
- Protección de datos con localForage/IndexedDB
- Opción de activar/desactivar backup automático desde el menú

### ⚡ Mejoras de Experiencia y Robustez
- Mejor experiencia móvil y PWA
- Feedback háptico y gestos táctiles
- Corrección de bugs en la visualización y persistencia de datos
- Mejoras en la restauración y validación de datos

### 🛡️ Licencia
- El proyecto ahora está protegido por una licencia restrictiva: no se permite la clonación, redistribución ni uso comercial sin consentimiento expreso del autor.
- Para uso, modificación o distribución, es necesario un acuerdo económico o licencia especial.
