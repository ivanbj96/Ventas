    Backup Automático a Telegram

    Configuración de Telegram
    Mínimo: 5 min, Máximo: 1440 min (24h)
    Guía paso a paso
    1. Abre Telegram y busca @BotFather.
    2. Envía /newbot y sigue las instrucciones para crear un nuevo bot.
      Guarda el Token que te entrega BotFather.
    3. Agrega tu bot al chat o grupo donde quieras recibir los backups.
      Si es grupo, hazlo administrador.
    4. Para obtener el Chat ID:
      • Busca el bot @userinfobot en Telegram y escríbele o agrégalo al grupo.
      • Te mostrará tu Chat ID o el del grupo.
    5. Ingresa el Token y Chat ID en el formulario de arriba y guarda.
    6. Configura el intervalo de respaldo automático (en minutos).
    7. Pulsa Probar Envío Manual para verificar que todo funciona.
    Nota: El backup enviará un archivo con todos tus datos de la app en formato JSON.
